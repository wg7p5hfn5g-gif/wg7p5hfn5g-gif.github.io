博客开张啦

你好，世界 👋

这是我的第一篇博客文章，博客由 Hexo 驱动，托管在 GitHub Pages 上。

这个博客用来做什么

  • 记录学习和生活中的点滴
  • 分享技术心得与踩坑经验
  • 沉淀思考，留下痕迹

博客是怎么搭起来的

  1. 用 hexo init 初始化博客框架
  2. 写文章只需要在 source/_posts/ 下新建 Markdown 文件
  3. 运行 hexo clean && hexo deploy 一键发布到 GitHub Pages

欢迎常来逛逛！
