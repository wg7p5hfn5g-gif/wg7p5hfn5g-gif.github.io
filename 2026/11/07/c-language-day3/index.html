C 语言学习笔记 · 第三天

C 语言学习笔记 · 第三天

今天的内容是公认的分水岭：字符串和指针。指针被说是 C 语言最难的部分，但第一天的目标是「先看懂、能写简单例子」，不追求一次吃透。

一、字符串：其实就是字符数组

C 语言没有专门的「字符串类型」，字符串就是一串字符的数组，结尾放一个 \0 表示结束。

char name[20] = "小明" 在内存里实际是这样的：

下标 0 1 2 3 4 … 19
内容 小 明 \0 垃圾值 垃圾值 垃圾值

\0 是字符串的结束标记，printf 靠它判断读到哪儿停。

⚠️ 坑 1：数组必须留够位置。char name[3] = "小明" 会出问题，因为「小明」在 UTF-8 里占 6 个字节，加上 \0 至少要 7 个位置。中文一个字通常占 3 字节，声明数组时给宽裕点。

六、今天的坑

  1. **字符串末尾有 \0**，数组要留够位置，中文一个字约占 3 字节
  2. 字符串不能用 == 比较、不能用 = 赋值，要用 strcmp 和 strcpy
  3. 指针必须先指向有效地址再用，否则是野指针，程序可能直接崩
  4. & 是取地址，* 是取值，两个符号别搞反
  5. 函数想改外部变量，必须传地址

七、小结

今天最核心的一句话：指针就是地址，& 拿地址，* 用地址。

  • 字符串 = 字符数组 + \0 结尾，配套 string.h 里的函数
  • 指针存地址，让函数能修改外部变量
  • 理解了指针，就理解了 scanf 为什么要加 &

指针这块今天只是入门，真正熟练得靠后面写代码慢慢磨。
