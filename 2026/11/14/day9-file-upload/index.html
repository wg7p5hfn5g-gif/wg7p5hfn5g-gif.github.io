渗透学习笔记 · 第九天：文件上传，我昨天的猜想对了一半

渗透学习第四天。昨天结尾我猜「文件上传也是注入家族成员，是『我的文件被当成了可执行代码』」——今天验证，结果对了一半。
老规矩：全部操作在本地 DVWA（127.0.0.1）完成，线上一个字节都不碰。

一、先说说 DVWA 的 File Upload Low

页面很朴素：一个上传按钮，加一行提示「上传你的头像」。我随手传了个 png，它回了一段路径：

看见那个路径我就明白了——文件被存进了网站目录，而且我能知道它存在哪、叫什么名字。这就是所有文件上传漏洞的起点：网站让我把文件放进了它能执行的地方。

二、猜想的验证：对了一半

我昨天猜的是「我的文件被当成了可执行代码」，验证后要修正成更准确的说法：

文件上传漏洞的本质不是「注入」，而是「我把一个可执行文件放进了网站目录，然后请求它，它就被执行了」。

区别在哪？SQL 注入和 XSS 是「数据越界变成代码」，而文件上传是「我直接交了一个代码文件，服务器还替我保管、还能替我运行」。所以它其实更像「我给服务器塞了一个后门，还能自己按门铃」。

那么「家族」的说法对不对？——算远亲。共同点还是那一条：信任边界没守住。

三、实操：上传一个 PHP 文件

Low 等级什么检查都没有。我建了一个 test.php：

我的 PHP 代码在服务器上跑起来了。 这一步的意义比看起来大：这意味着服务器愿意执行我提供的任何代码。

四、「一句话木马」到底是什么

网上到处是这四个字，我觉得被神化了。它的原理其实简单到无聊：

拆开看：

  • $_POST['cmd'] —— 服务器接收我从表单发来的一段字符串
  • eval() —— 把这段字符串当成 PHP 代码执行
  • @ —— 抑制报错，免得暴露信息

就这三样。我传上去这个文件之后，以后只要往它 POST 一句 system('whoami')，服务器就会执行 whoami 并把结果返回来。

所以「一句话木马」不是病毒，是一个「远程代码执行入口」。中国菜刀、蚁剑这类工具做的事也很朴素：把「发请求 → 拿回显」包装成图形界面，让我像操作本地文件夹一样操作服务器。

（这些东西我只在自己电脑的靶场里理解原理，不会传任何真实服务器。这不是技巧问题，是底线问题。）

五、Low 之外的等级：过滤器长什么样

我顺手试了 Medium，传 .php 被拒了，提示只允许 jpg/png。看了源码，判断方式是这样的：

它信的是请求里的 Content-Type——而这个是浏览器发的、抓包能随便改的。所以这类检查本质上是「问坏人你是不是坏人」。

真正靠得住的做法，是不信任何前端信息，只在服务端做白名单：

防御措施 为什么有效
后缀白名单（只允许 jpg/png/zip 等明确列表） 黑名单永远漏（php3/phtml/大小写/双后缀）
服务端重命名（随机文件名 + 保留原后缀） 让我猜不到路径，也就访问不到
上传目录禁止脚本执行 最关键的兜底：文件传进来也跑不起来
文件存到 Web 目录之外 根本访问不到，只能由程序读出来再输出
校验真实文件头（magic number） 图片就是图片，改后缀没用

我觉得最值得记住的是第三条：哪怕前两条都被绕过，只要上传目录禁了 PHP 解析，我这个 shell 就是一块废铁。这是「纵深防御」的典型例子——不是靠一招制胜，而是让攻击者要连续突破好几层。

六、今天我踩的坑

坑 我的经历
传上去访问 404 路径写错了，DVWA 的上传目录是 hackable/uploads/，要按返回的完整路径访问
php 文件里混了中文引号 又是这个老毛病！echo 后面的引号打成中文的，页面空白什么都不输出。我现在养成习惯了：写代码前先确认输入法是英文
以为一句话木马很复杂 真看到就 5 个字符的 eval，失望了两秒，但也踏实了——原理越简单越难防
想去找现成的「工具」 差点去搜菜刀下载，后来想明白：工具会过期，原理不会。靶场里手写 POST 请求比装个工具学到的多
手痒想传线上 同前几天，忍住。上传到别人服务器 = 未授权访问 + 可能构成破坏计算机信息系统罪

七、这四天的串连

我给自己画了条线，发现四天的东西能连成一个整体：

天数 漏洞 我做的事 一句话本质
第六天 概念 学 HTTP、搭靶场 一切从「请求」开始
第七天 SQL 注入 手工四步法掏库 数据被当成 SQL 执行
第八天 XSS 弹 Cookie 数据被当成 JS 执行
第九天 文件上传 传 PHP 后门 文件被当成代码执行

四天下来，我脑子里只剩一句总结：所有漏洞都在同一个地方出事——服务器分不清「我给的到底是数据还是代码」。

八、明天的计划

我想换个角度：这几天一直在打 DVWA，但真实的渗透测试不是「打开页面找输入框」。明天想学 信息收集——Nmap 扫端口、看目录结构、指纹识别，这是真实渗透的第一步，也是我目前最空白的一块。

如果 DVWA 还有没打完的（CSRF、命令注入、暴力破解），也可以先补完再走。明天看状态决定。
