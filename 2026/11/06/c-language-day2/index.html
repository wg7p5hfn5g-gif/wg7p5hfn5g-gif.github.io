C 语言学习笔记 · 第二天

C 语言学习笔记 · 第二天

第一天学会了变量、输入输出和循环，今天按计划往前推进：数组、函数，最后用一个小游戏把学到的东西串起来。

一、数组：一次存一串数据

第一天用变量存一个数，如果有 5 个学生的成绩呢？定义 5 个变量太笨了，这时候就用数组。

几个关键点：

  • int scores[5] 表示「能装 5 个整数」的数组
  • 访问元素用 scores[0]、scores[1]……下标从 0 开始
  • 最后一个元素是 scores[4]，不是 scores[5]
元素 下标 值
第 1 个 [0] 90
第 2 个 [1] 85
第 5 个 [4] 68

⚠️ 今天第一个坑：数组下标从 0 开始。5 个元素的数组，合法下标是 0~4。写 scores[5] 不会报错，但读到的是内存里的垃圾数据，甚至可能让程序崩溃——这种错误最难查。

三、函数：把代码打包

写多了会发现很多代码在重复。函数就是「给一段代码起个名字，以后叫名字就执行它」。

拆开看函数的结构：

四、变量作用域：函数里的变量外面看不见

简单记：变量从定义它的那行开始，到它所在的大括号结束为止有效。所以函数的局部变量不会互相干扰，这也是函数好用的原因之一。

五、实战：猜数字小游戏

把今天和第一天学的都用上——循环、判断、函数、随机数。

两个新东西：

  • rand() 生成随机数，但直接用它每次结果都一样，必须先用 srand(time(NULL)) 播种
  • rand() % 100 + 1 是固定套路：% 100 得到 099，再加 1 就是 1100

while (1) 是「一直循环」的写法，配合 break 在合适的时候跳出来——这个组合很常用。

六、今天的坑

  1. 数组下标从 0 开始，int a[5] 的合法下标是 0~4，越界不报错但结果乱掉
  2. 函数要先定义或声明再使用，否则编译警告
  3. rand() 不播种每次结果都一样，记得 srand(time(NULL))
  4. 用 & 读入数组元素：scanf("%d", &scores[i]);，漏了就崩

七、小结

今天学会的：

  1. 数组一次存多个同类型数据，靠「for + 下标」遍历
  2. 函数把重复逻辑打包，参数传进去、return 交结果
  3. 变量有作用域，出了大括号就失效
  4. 用循环 + 判断 + 随机数，做出了第一个能玩的小程序

八、明天计划

  • 学字符串，处理文字而不只是数字
  • 学指针——听说这是 C 语言最难也最核心的部分
  • 把猜数字游戏加上「最多猜 7 次」的限制

写完猜数字游戏跑起来的那一刻，比 Hello World 有意思多了 🎮
