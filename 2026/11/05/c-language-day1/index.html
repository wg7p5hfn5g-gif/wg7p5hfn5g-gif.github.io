C 语言学习笔记 · 第一天

C 语言学习笔记 · 第一天

今天正式开始学 C 语言。这篇文章记录第一天的收获，包括第一个程序、变量、输入输出和一些容易踩的坑。写给同样刚起步的自己，也写给以后回头看时的我。

一、第一个程序：Hello World

逐行拆解：

代码 作用
#include <stdio.h> 引入标准输入输出库，printf 就住在这里
int main(void) 程序入口，每个 C 程序都从这里开始执行
printf("...") 把内容打印到屏幕上
\n 换行符，不写的话下次输出会挤在同一行
return 0; 告诉系统「程序正常结束」

编译运行（用 gcc）：

💡 笔记：C 语言是编译型语言，写完的 .c 文件必须先用编译器「翻译」成可执行文件，电脑才认。

二、变量与数据类型

C 语言是强类型语言：用变量前必须先声明类型，而且类型定下来就不能随便改。

常用类型和占位符对照：

类型 含义 占位符 例子
int 整数 %d int a = 10;
float 单精度小数 %f float f = 3.14f;
double 双精度小数 %lf / %f double d = 3.14159;
char 单个字符 %c char c = 'x';

⚠️ 踩坑记录：char 用单引号 'A'，双引号 "A" 是字符串，两者完全不同。我第一次就写错了，编译报错一堆。

三、输入：scanf

有了变量，就能让用户自己输入数据：

⚠️ 今天最大的坑：scanf 里的变量**必须加 &**（取地址符）。不加的话程序可能直接崩溃。

记忆方法：scanf 要「把数据放进这个地址」，所以得告诉它变量住在哪；printf 只是「读出值」，不需要地址。

四、运算符

⚠️ 重点坑：两个整数相除，结果还是整数。10 / 3 得到 3 而不是 3.33。想要小数结果，至少一边得是小数：

五、条件判断：if / else

⚠️ 坑：判断相等用 ==（两个等号），= 是赋值。if (a = 5) 不会报错，但逻辑全错，这个错误特别隐蔽。

六、循环：for 和 while

for 的三个部分：初始化；条件；每轮结束后做什么。我把它记成「从哪开始、到哪停、每次走几步」。

七、第一天小结

今天学到的核心概念：

  1. C 程序必须编译才能运行，入口是 main 函数
  2. 变量要先声明类型，常见的有 int、float、double、char
  3. printf 输出用占位符，scanf 输入记得加 &
  4. 整数除法会丢小数，判断相等用 == 不是 =
  5. 分支用 if/else，循环用 for/while

八、明天计划

  • 学数组，试着存一串数字
  • 学函数，把重复代码抽出来
  • 手写一个「猜数字」小游戏练手

第一天结束，代码虽然简单，但能跑起来的那一刻真的挺爽的 🎉
